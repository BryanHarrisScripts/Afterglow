# Contributing to Afterglow

Afterglow accepts focused corrections, accessibility improvements, metadata repairs, PlotPickle compatibility fixes and clearly licensed creative proposals.

## Before contributing

- Do not include credentials, private contact information, unpublished third-party work or material you do not have permission to share.
- Identify every new image, font, audio file, video file or substantial excerpt and document its creator, source and licence.
- Keep generated media separate from human-authored source material and state how it was produced.
- Use a branch and pull request. Do not change main directly.
- Complete the privacy, rights and attribution checklist in the pull-request template.

## Current licence boundary

The repository's README and LICENSE currently name different Creative Commons licences. Until the maintainer resolves that conflict and publishes one canonical licence scope, do not submit new creative material for redistribution. Corrections that do not add creative content may still be proposed.

Submitting a pull request does not transfer ownership of unrelated work. A contributor must have the right to submit every copyrightable contribution and must accept the canonical contribution licence once it is resolved.

## Review

A proposal should explain what changed, why it belongs in Afterglow, which files and assets are affected, and how the result was validated. Only the repository owner or an authorized maintainer may merge a proposal.
