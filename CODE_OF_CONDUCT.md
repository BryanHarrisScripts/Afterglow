# Code of conduct

Afterglow welcomes respectful creative and technical review.

Participants must:

- critique the work without attacking the person;
- respect authorship, attribution, privacy and creative ownership;
- never publish contact information, credentials or private story material;
- avoid harassment, discrimination, threats, sexualized conduct and deliberate disruption; and
- follow maintainer decisions about safety, licensing, attribution and repository access.

Maintainers may edit or remove contributions, comments or access that violate these expectations.

For a sensitive conduct report, contact the repository owner privately. If no private channel is available, use a private security advisory titled "Conduct report" and include no unnecessary personal information.
